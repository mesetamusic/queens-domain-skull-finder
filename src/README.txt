Queen's Domain Skull Finder  v1.0
=================================

Shows which of the 69 Silver Skulls you still need, and where they are.

HOW TO USE
  1. Double-click SkullFinder.exe.
  2. That's it. It finds your game and your latest save automatically.

  - The list shows each missing skull, grouped by area. Click one for details:
    the nearest Crystal Monument, nearby landmarks (Wind Gems, Wing Altars,
    statues, secret walls, chests...), and how high or low the skull is
    compared to them.
  - Leave it open while you play. It refreshes by itself every time the game saves.
  - "Show collected skulls too" lists all 69.
  - "Choose save..." checks a different save file.
  - "Game folder..." is only needed if the game wasn't found automatically
    (Steam: right-click Queen's Domain > Manage > Browse local files, pick that folder).

HOW IT WORKS
  The game marks every skull you've picked up in your save file. Skull Finder
  reads the skull locations from the game's own files, then checks which ones
  your save hasn't marked yet. Nothing is downloaded and nothing is uploaded.

  It is READ-ONLY. It never changes your save or the game.

NOTES
  - Distances are in metres. "Higher/lower than it" compares the skull's height
    with that landmark, which is often the best clue (rooftops, ledges, pits).
  - The game has no compass, so directions aren't given; use the landmarks.
  - Windows may show a SmartScreen warning because the app isn't code-signed:
    click "More info" > "Run anyway".
  - Saves are read from %LOCALAPPDATA%\QueensDomain\Saved\SaveGames.
    The app keeps a small cache in %LOCALAPPDATA%\QDSkullFinder (safe to delete).
  - A game update can change file formats. If it stops working after a patch,
    it'll tell you instead of showing wrong results.
